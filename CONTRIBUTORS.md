# Contributors

Thank you to everyone who has helped make Blerg better. Public releases are published as a single
commit, so individual commit authorship does not show up in the public history; this file is where
we name the people behind the work.

When we build on a contribution instead of merging it as-is, we still list it here and in the release
notes for the version that ships it.
